# Live Phish <img src="/assets/icons/live-phish-icon.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

Music Assistant has support for streaming your music from <a href="https://www.livephish.com" target="_blank" rel="noopener noreferrer">Live Phish</a>. Contributed and maintained by <a href="https://github.com/brian10048" target="_blank" rel="noopener noreferrer">Brian</a>

Live Phish is a subscription service for Live Phish concert recordings.  Access official recordings, exclusive archives and more.


> [!NOTE]
> A paid subscription is required to use this source
    
## Features

|           |                     |
|:-----------------------|:---------------------:|
| Subscription FREE | No |
| Self-Hosted Local Media   | No |
| Media Types Supported | Artists, Albums, Tracks, Playlists |
| [Recommendations](/ui/#view---discover) Supported | Yes |
| Lyrics Supported | No |
| [Endless Mix](/ui/#track-menu) | No |
| Artist Top Tracks Support                       |            No                      |
| Similar Artists Support                         |            No                      |
| Similar Tracks Support                          |            No                      | 
| Maximum Stream Quality | FLAC 192kHz 24 bit |
| Login Method | Password |


## Configuration

To configure, input a username and password.

## Usage

- Check the Discover page for Recent Shows
- Browse by Artist, Song, Album, Year, or Tour just like the Live Phish app

## Known Issues / Notes

There are no images for artists, so the default image for an artist defaults to the Live Phish logo
