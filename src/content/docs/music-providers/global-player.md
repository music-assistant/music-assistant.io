# Global Player <img src="/assets/icons/global-player-icon.svg" alt="Global Player logo" style="width: 70px; float: right;" loading="lazy" />

Music Assistant has support for <a href="https://www.globalplayer.com" target="_blank" rel="noopener noreferrer">Global Player</a>, bringing UK radio stations from Global Media into Music Assistant. Contributed and maintained by <a href="https://github.com/scarrington76" target="_blank" rel="noopener noreferrer">scarrington76</a>

Global is one of the UK's premier commercial radio broadcasters. Its platform, Global Player, offers live streams of well-known national and regional radio stations across music, news, and entertainment, including Capital, Heart, Classic FM, Smooth, Radio X, LBC, and Gold, along with their regional variations and brand spin-offs.

This source adds Global Player's live stations to Music Assistant as radio stations.

> [!CAUTION]
> This is an unofficial implementation and is not affiliated with or endorsed by Global Media.

## Features

|           |                     |
|:-----------------------|:---------------------:|
| Subscription FREE | Yes |
| Self-Hosted Local Media | No |
| Media Types Supported | Radio |
| [Recommendations](/ui/#view---discover) Supported | No |
| Lyrics Supported | No |
| [Endless Mix](/ui/#track-menu) | No |
| Artist Top Tracks Support                       |            No                      |
| Similar Artists Support                         |            No                      |
| Similar Tracks Support                          |            No                      |
| Maximum Stream Quality | AAC 128kbps |
| Login Method | None |

## Configuration

No account or credentials are required. To add the provider, go to **Settings → Music Sources → Add a music source → Global Player** and click the save button.

## Usage

Use the browse view (*Browse → Global Player*) or search to find stations to play or add to your library.

## Known Issues / Notes

- Only live radio streams are supported. On-demand programmes, catch-up audio, and podcasts from Global Player are not currently available
- Seeking and pausing are not supported on live radio streams
