# Plugins

Plugins add things that sit alongside playback rather than being part of it.

A [music source](/music-providers/) brings music in. A [player provider](/player-support/) sends it out to a speaker. A plugin does something else entirely: it might host a party your guests queue tracks from, run a music quiz on the TV, let another app send audio *to* Music Assistant over AirPlay or DLNA, or report what you played to Last.fm.

Plugins are optional. Music Assistant works perfectly well without any of them.

## Adding a plugin

Go to **Settings → Plugins → Add a plugin**, which opens the [Marketplace](/settings/marketplace/) on its plugins, and pick one. Every plugin has its own page in this section covering what it does and how to configure it.

**Settings → Plugins** lists the plugins that are set up. When the list holds more than one kind, chips above it filter on what the plugins do: **AI**, **Text-to-speech**, **Scrobbling**, **Assistants**, **Lights & visuals**, **Mixes & recommendations**, **Fun & games** and **Other**. Only the chips that match a plugin in the list show, and **All** shows every plugin again. The rows carry the same labels, except **Other**.

The plugins that let another app play into Music Assistant, such as [Spotify Connect](/plugins/spotify-connect/), are live sources: they are listed with the music sources, and added with **Settings → Music → Add a music source**. The [Home Assistant](/ha-plugin/) plugin is set up under **Settings → System → Home Assistant**, and the MCP server built into Music Assistant is switched on and off on [**Settings → AI**](/settings/ai/#access-for-ai-assistants).

Some plugins depend on something else being set up first. For example, the [Home Assistant](/ha-plugin/) plugin needs a Home Assistant instance it can connect to.
