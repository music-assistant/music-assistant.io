# About <img src="/assets/icons/about-icon.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

This page has information about the MA server, a series of useful statistics, and links to useful information.

- <b>Server information.</b> The first section, with a pencil to edit it. It lists the **Server name**, **Server version**, **Internal URL**, **Remote access**, **Clock offset** and, when Music Assistant runs as one, **Home Assistant app**
- <b>Stats.</b> Statistics about the server and the library
- <b>Links.</b> Links to useful information
